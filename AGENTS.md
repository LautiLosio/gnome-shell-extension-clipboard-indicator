# Project documentation and attribution

- Credit the original Clipboard Indicator project, Yotam Bar-On (Tudmotu), its maintainers, and contributors prominently in the README and derivative project descriptions.
- Preserve the original MIT copyright and license notice. Do not imply upstream endorses this fork or authored its changes.
- Keep the README's AI development disclosure visible and accurate. Distinguish AI-assisted fork changes from the original project's work; do not imply upstream was AI-generated.
- Describe implemented changes separately from goals, benchmark measurements, unverified benefits, missing features, and known limitations.
- For comparisons, identify the upstream baseline. Do not claim an upstream issue is fixed without evidence covering the reported failure path.
